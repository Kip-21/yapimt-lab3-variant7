# Лабораторная работа 3 — вариант 7

По исходной строке строится палиндром: к строке дописывается её обратная запись.
Например, `abcd` превращается в `abcddcba`.

Ввод и вывод находятся в `code/main.cpp`, обработка — в `code/palindrome.asm`.
Процедура использует цепочечные команды. Данные передаются аргументами по соглашению `cdecl`.

## Запуск

Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив либо выполните:

```powershell
git clone https://github.com/Kip-21/yapimt-lab3-variant7.git
cd yapimt-lab3-variant7
```

Нужна Windows и Visual Studio либо Build Tools с компонентом **«Разработка классических приложений на C++»** (MSVC x86/x64 и Windows SDK). MASM входит в комплект инструментов C++.

1. Откройте папку `code`.
2. Запустите `run.bat` двойным щелчком. Он соберёт программу и откроет ввод.
3. Введите строку и нажмите Enter. Результат появится после `Palindrome:`.

`Enter a string` означает «Введите строку». Приглашения написаны латиницей; русские буквы во вводе поддерживаются в CP866. Предел — 255 байтов: русская буква в CP866 занимает один байт. Пробелы, регистр и знаки препинания сохраняются. Для пустой строки достаточно нажать Enter.

Можно собрать и запустить из PowerShell, открытого в папке работы:

```powershell
.\code\build.bat
.\code\build\lab3.exe
```

Скрипт сам находит Visual Studio и выбирает инструменты **x86**. Файлы сборки помещаются в `code/build`. Код выхода 0 означает успешное выполнение, 1 — ошибку ввода или превышение длины. При перенаправлении ввода файл должен быть в CP866; UTF-8 для этой программы не подходит.

Готовая программа также включена в репозиторий: `code/build/lab3.exe`. Её можно запустить без пересборки из терминала. После изменения исходников используйте `build.bat` или `run.bat`.

## Запуск в Visual Studio

1. Создайте пустой проект C++ для консольного приложения.
2. Добавьте `code/main.cpp` и `code/palindrome.asm`.
3. Выберите платформу **Win32 (x86)**.
4. В меню проекта **Зависимости сборки → Настройки сборки** включите **masm**. Для `palindrome.asm` проверьте тип элемента **Microsoft Macro Assembler**.
5. Если проект требует предкомпилированный заголовок, отключите его в свойствах C/C++ → Предкомпилированные заголовки.
6. Соберите проект и запустите его через Ctrl+F5.

## Отчёт

В `report` находятся [исходник LaTeX](report/report.tex) и [готовый PDF](report/report.pdf), без титульного листа. Оформление взято из отчёта 2-й работы.

Чтобы пересобрать отчёт, установите MiKTeX или TeX Live и запустите:

```powershell
cd report
xelatex -interaction=nonstopmode -halt-on-error report.tex
```

Нужны шрифты Times New Roman и Consolas. Файлы с кодом подключаются в отчёт из соседней папки `code`, поэтому расположение папок нужно сохранить. Краткие ответы к защите вынесены в `report/Вопросы к защите.md`.

```powershell
python tests/run_tests.py
.\tests\check_abi.bat
```
