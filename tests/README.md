# Проверка лабораторной работы 3

Перед проверкой соберите программу командой `code\build.bat` из корня репозитория.

```powershell
python tests/run_tests.py
.\tests\check_abi.bat
```

`run_tests.py` запускает готовую программу, подаёт строки в CP866 и сравнивает вывод, сообщения об ошибках и коды завершения. Проверяются 18 основных случаев и строки всех длин от 0 до 255 байтов с фиксированным начальным значением генератора. Всего 274 теста. Результаты сохраняются в `results.json`.

`check_abi.cpp` вызывает ту же процедуру MASM для каждой длины от 0 до 255 и проверяет:

- строку результата и завершающий нулевой байт;
- неизменность исходной строки;
- контрольные байты до результата и сразу после него;
- сохранение EBX, ESI, EDI, EBP и восстановление ESP после удаления аргументов;
- сброшенный флаг направления DF.

Для сборки этой проверки используется MSVC x86. Вставка `__asm` находится только в проверочном коде; сама лабораторная программа состоит из отдельного модуля C++ и отдельного модуля MASM. Всего 256 проверок процедуры. Исполняемый файл проверки помещается в `tests/build`.
